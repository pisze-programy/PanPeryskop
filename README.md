## Stack

- **iOS:** SwiftUI, iOS 18+ (XcodeGen project)
- **Map:** MapLibre Native + OSM
- **Backend:** Cloudflare Workers (Hono) + D1 + R2 + Queues
- **Auth:** Sign in with Apple, per-device bans
- **Website:** Cloudflare Pages landing
